# 示例：把一个虚构项目整理成公开资料

> 教学示例：以下“青叶记”是虚构项目，不代表真实产品、用户或效果。网址使用保留示例域名，不能拿去当真实来源发布。

| 字段 | 示例内容 |
| --- | --- |
| 项目名 | 青叶记 |
| 项目一句话 | 帮助小型读书社群整理公开活动说明与读书笔记的示例工具 |
| 官网 | `https://example.com/`（占位，不作为事实来源） |
| 目标读者 | 每周组织一次活动、需要重复整理通知的社群组织者 |
| 用户问题 | 怎样把活动时间、书目和参与方式写清楚？ |
| 内容主题 | 一份读书活动通知应包含哪些信息 |
| 可公开资料 | 实际项目应换成自己的官方功能说明与授权素材 |
| 不可公开内容 | 参与者电话、群聊、私人笔记、账号凭据 |
| 语气 | 具体、清楚，先给例子再解释 |
| 目标产出 | 一篇图文草稿，封面文字“写清一场读书活动” |

## 替换后再用

先换成真实项目与可访问来源。价格、用户数、效率提升和服务范围没有来源时留空；不要让 Agent 补造。将准备好的资料交给[内容提示词](../prompts/content.md)，再按[入门教程](../docs/getting-started.md)保存。
