# 示例：一份图文内容任务

> 本例对应虚构项目“青叶记”，用于学习填写，不代表已生成或已发布任务。

```yaml
project: 青叶记（教学示例）
topic: 一份读书活动通知应包含哪些信息
reader: 小型读书社群的组织者
content_type: 图文
working_title: 第一次组织读书活动，通知里要写清哪六件事？
summary: 用清单和示例说明书目、时间、地点、参与方式、准备事项和联系渠道。
tags:
  - 活动通知
  - 读书社群
  - 内容模板
cover_text: 写清一场读书活动
style: 清楚、具体、避免夸大
source_requirements:
  - 替换为真实项目的公开帮助与已授权资料
  - 不使用群成员个人信息
publication: 仅准备草稿，尚未授权投稿
```

## 交给 Agent 的验收要求

文章先回答“通知里写什么”，再给一个完整模板；时间、地点与联系人全部使用占位符。不要编造青叶记已有功能、用户量或效率数据。标题、说明、标签、封面文字、正文分别输出；保存前核对事实与图片。

下一步：用[制作内容提示词](../prompts/content.md)准备内容。公开发布需要替换所有教学占位，并另行明确目标平台与账号。
