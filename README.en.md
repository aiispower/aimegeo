![aimeGeo campaign cover: start with a goal and use familiar AI tools to create, publish and monitor citations](docs/assets/promotion/01-dialogue-geo.png)

**Start with a sentence. Keep GEO moving through conversation.** Tell your familiar AI assistant about your website, product, project or content direction, then let the Agent advance planning, writing, illustrations and multi-platform publishing. **For GEO and creator workflows:** add AI mention and citation checks when you want to observe AI visibility.

aimeGeo is independently developed and free to use. This repository provides guides, Skills, prompts and generic helper scripts; private product source and user data are excluded. External AI subscriptions, image services and proxies may charge separately.

## Create → Publish → Monitor

- **Create content:** research, plan, write, edit and illustrate; prepare titles, tags, covers and body content.
- **Publish:** advance text/image or video tasks for the selected platform and account, keeping actual receipts.
- **Monitor citations:** for GEO goals, optionally retain AI answers, brand mentions and source citations for later checks.

EasyBR assists with independent signed-in browser environments, proxy IPs and fingerprints. Easy WebBridge operates the selected signed-in browser. Environment separation assists account management; account activity and publishing frequency must follow platform rules.

## Can I use it for regular creator work?

Yes. Content planning, writing, editing, illustrations, account environments and publishing use the same workflow. Citation monitoring is optional for GEO goals; creator tasks do not have to run it. Video publishing uses existing materials and the currently available workflow.
