# aimeGeo 第一次使用：从一个网站到一次 AI 引用检测

准备一个网站、产品或项目，让 AI 帮你整理资料、制作内容、发布并检测引用。第一次建议只做“一份资料、一篇文章、一个账号、一组问题”，便于看清每一步的结果。

## 先准备什么

- 已完成[安装与登录](installation.md)，网页与本机客户端使用同一账号。
- 一个你有权公开介绍的项目，以及可核对的官网、帮助或资料。
- 一个你有权使用的发布账号，登录在已连接 Easy WebBridge 的浏览器中。
- 一组用户真实会问的问题，避免只问“请引用我的网站”。

可从[示例项目资料](../examples/project-brief.md)、[示例内容任务](../examples/content-task.md)和[示例问题集](../examples/citation-questions.md)开始。这些均为虚构教学资料，不能当作产品承诺或真实发布记录。

## 第一步：制作内容

1. 打开[项目与知识资料](https://geo.aimmme.com/ag01/geo/prep/knowledge-base)，整理项目名称、目标人群、推广主题、官网和原始来源。
2. 将[内容提示词](../prompts/content.md)交给熟悉的 Agent，补齐资料和预期读者；请它先列事实与待确认项，再给选题和草稿。
3. 请外部 Agent 按提示词生成草稿；打开[文章](https://geo.aimmme.com/ag01/geo/writing/articles)，点击“添加文章”。初次使用不需要先创建站内写作任务。
4. 填写“文章标题”“文章摘要”“文章分类”，在“正文内容”粘贴 Markdown 草稿；用“添加图片”上传封面与插图，或用“添加链接”补充图片。核对事实、来源和图片后，点击“创建”，重新打开文章确认保存结果。提示词中的标签作为投稿准备材料，按目标平台要求补充。
5. 在“内容类型”选择图文或视频后再保存。视频需填写真实“视频素材”和“视频说明”。首次建议先完成一篇图文。

站内[写作任务](https://geo.aimmme.com/ag01/geo/writing/tasks)是可选的自动写作入口，需要已可用的本机 Codex 写作环境。没有配置时，继续使用上面的外部 Agent + 添加文章路径；如需启用站内自动写作，查看[官方帮助](https://geo.aimmme.com/docs/)或联系支持，不需要寻找本仓库之外的私有脚本。

封面可按实际已配置的能力选择 Image2、豆包 Seedream 或 Remotion。Remotion 用排版与模板渲染图片，多尺寸和风格由所选模板决定；外部模型的费用、额度和授权另行确认。

## 第二步：自动发布

1. 在[账号授权](https://geo.aimmme.com/ag01/geo/publish/self-accounts)同步目标账号并核对身份。
2. 在[发布任务](https://geo.aimmme.com/ag01/geo/publish/self-tasks)选择已保存内容和账号。先看[平台能力表](platforms-and-models.md)，选择当前可用且适合该类型的平台。
3. 检查标题、正文或视频、封面、分类及平台要求。确认你希望发布后再执行；验证码和额外安全验证在平台原生界面完成。
4. 进入[发布记录](https://geo.aimmme.com/ag01/geo/publish/self-records)，查看回执与公开链接。草稿、上传完成、已提交、审核中和已公开分别记录。
5. 回执未知时先核对原任务与平台管理页，不重复投稿。百家号当前只保存草稿，需要在平台完成最终发布。

## 第三步：检测引用

1. 内容已公开且链接可访问后，从发布记录进入“查 AI 引用”，或打开[文章 AI 引用检测](https://geo.aimmme.com/ag01/geo/data/article-citations)。
2. 选择已可用的检测通道，录入目标文章与问题。网页通道需要目标 AI 平台已登录、联网回答可用和正确的浏览器环境。
3. 查看“回答与证据”：原始回答、采集时间、提及、原生引用与实际来源 URL。
4. 在[文章 AI 引用检测](https://geo.aimmme.com/ag01/geo/data/article-citations)的“检测记录”查看已保存问题与证据；后续日期点击对应记录的“手动复测”，比较同题结果。

[搜索收录监测](https://geo.aimmme.com/ag01/geo/data/index-monitor)检查的是百度、必应搜索收录，属于独立观测，不等于 AI 引用检测。

没有回答是未采集；回答提到品牌不等于引用了文章；有引用也只说明该次回答命中了该来源。发布与 AI 发现之间可能有延迟，不用立即反复检测代替持续复测。

## 强力辅助：EasyBR 环境隔离

EasyBR 用于管理多个独立浏览器环境，可分别配置代理 IP 和浏览器指纹；Easy WebBridge 在选定环境里操作已登录网页。为不同账号明确绑定环境，发布前再核对身份。隔离配置不能保证平台永远不关联账号，也不应代替平台授权或账号规则。

完成以上步骤后，你应能找到一份保存的内容、一个真实发布状态和一次有证据的检测结果。更多细节见[完整流程](workflow.md)、[AI 使用方法](ai-assistant.md)和[真实截图](screenshot-index.md)。
