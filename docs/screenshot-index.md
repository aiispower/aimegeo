# aimeGeo 基础界面截图

以下包含产品介绍、公开下载页和四个基础列表。四张列表为真实产品组件渲染的虚构演示记录，并标注“演示数据”；用于认识标题、账号、平台、图文/视频类型、任务状态及引用检测字段，不代表真实客户、发布成果或检测业绩。没有向业务库写入演示记录，也没有触发账号同步、投稿或 AI 检测。

[功能展示](promotion-assets.md) · 以下为工作界面。

## 历史产品介绍界面

介绍“制作内容 → 自动发布 → 检测引用”的整体路径，并说明 EasyBR 浏览器协作。宣传清单与实际可用能力的差别见[平台与模型说明](platforms-and-models.md)。

![aimeGeo 宣传界面与三步工作流](assets/screenshots/01-promotion.png)

## 官方下载中心

按系统选择国内或海外镜像。页面版本信息是截图当时的展示，下载时应重新打开[官方页面](https://geo.aimmme.com/download/)，不要仅依据截图里的旧版本号。

![aimeGeo 官方客户端下载中心](assets/screenshots/02-download-center.png)

## 文章列表

查看文章标题、类型、分类、配图和操作入口。首次使用从“添加文章”开始，具体步骤见[新手指南](getting-started.md)。

![aimeGeo 文章列表，虚构演示数据](assets/screenshots/03-article-list.png)

## 账号授权列表

了解平台、账号身份、浏览器环境与连接操作的位置。实际操作使用本人已登录的目标浏览器，检查账号身份后再继续。

![aimeGeo 账号授权列表，不含真实账号](assets/screenshots/04-account-list.png)

## 发布任务列表

查看任务来源、目标账号、内容类型、状态与操作入口；这张图只展示界面，不表示任何平台已实发成功。

![aimeGeo 发布任务列表，虚构演示数据](assets/screenshots/05-publish-list.png)

## AI 引用监测列表

按产品或项目定位检测对象，查看引用任务、问题和检测记录入口。AI 同题复测在引用检测记录中进行；百度/必应搜索收录是另一项监测。

![aimeGeo AI 引用监测列表，虚构演示数据](assets/screenshots/06-citation-list.png)

新版站内帮助见 [官网帮助文档](https://geo.aimmme.com/docs/)。真实业务操作请按[使用流程](workflow.md)执行。界面随版本更新，截图用于认识字段与入口，不代替当前安装版本的实际结果。
