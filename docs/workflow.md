# aimeGeo GEO 工作流：制作内容 → 自动发布 → 检测引用

GEO（生成式引擎优化）关注内容能否在 AI 的回答中被发现、提及和引用。aimeGeo 把内容资料、发布账号、平台回执与检测记录连接起来，便于持续改进内容；它不承诺任何平台必收录或排名。

## 一张流程表

| 阶段 | 输入 | 操作 | 可核对的产出 |
| --- | --- | --- | --- |
| 制作内容 | 网站、产品、项目、原始资料 | 整理主题、外部 Agent 起稿、添加文章与配图 | 保存的标题、说明、标签、封面、正文或视频 |
| 自动发布 | 已保存的内容与明确账号 | 同步账号、创建任务、执行并回读 | 草稿/提交/审核/公开状态及平台链接 |
| 检测引用 | 公开链接、固定问题集 | 采集回答、检查引用、后续同题复测 | 原始回答、时间、目标链接和检测结果 |
| EasyBR 辅助 | 多账号及登录环境 | 隔离环境、代理 IP 与指纹配置 | 账号与浏览器环境绑定，身份核对记录 |

操作截图见[截图索引](screenshot-index.md)。初次使用可以按[入门教程](getting-started.md)完成一条小流程。

## 制作内容：让资料支持结论

先整理可公开事实，再决定选题。每个结论尽量关联原始来源；无法核验的价格、用户量、合作、认证与性能数据不写成事实。保留项目和推广主题，避免多项目混用资料。

建议文章包含：一句话回答、适用人群、使用步骤、具体示例、限制与常见问题。标题表达一个清楚的问题，正文自然使用项目名和相关术语，不堆砌关键词，也不编造“权威测评”或虚假用户案例。

在文章页面实际查看封面和插图：文字是否正确、是否清晰、是否切边，横竖版是否适合目标平台。AI 模型生图、模板排版与 Remotion 渲染是不同方式；免费系统能力不意味着第三方模型调用无限免费。

新手可直接使用[内容提示词](../prompts/content.md)让外部 Agent 准备草稿，再到文章页点击“添加文章”，填写标题、摘要、分类与 Markdown 正文，添加图片后点击“创建”。无需先建立站内写作任务。站内自动写作是可选能力，尚未配置时查看[官方帮助](https://geo.aimmme.com/docs/)或联系支持；详见[AI 使用方法](ai-assistant.md)。

## 自动发布：用回执判断进度

在内容制作时确定图文或视频；发布任务沿用已保存的类型。视频说明中的链接不自动变成视频素材，缺少真实视频时先补素材。

1. 读取目标账号绑定的环境，确认平台页面确实登录了你要使用的账号。
2. 逐项检查标题、正文或视频、封面、标签、声明与分类。
3. 只执行一次投稿，保存任务状态；等待平台审核与回执。
4. 用平台管理页或公开链接核对结果，再到发布记录检查。
5. 结果不确定时保留原任务并排查，避免重复发表。

“已处理”不能独立证明内容公开，“上传成功”也不代表平台审核通过。目录图标只是产品识别信息，真实发布范围以[平台能力表](platforms-and-models.md)及客户端版本为准。

## 检测引用：区分三个问题

- **有没有回答？** 采集失败、超时或登录验证不能记作“未收录”。
- **有没有提及？** 品牌或产品名被提到，只说明回答出现了该名称。
- **有没有引用？** 检查 AI 原生来源是否指向目标文章或页面，核对 URL，不能只看相似标题。

每次记录问题原文、平台/通道、采集时间、回答、引用 URL 与目标文章版本。比较时保持问题一致，并说明有效回答数量；一次观测不足以证明全网收录率。

建议在公开链接稳定后安排延迟检测与后续复测；没有引用时先检查公开可访问性、事实清晰度、标题与用户问题的关系，再小步修改。不要把频繁重问造成的随机波动当成优化成效。

在“文章 AI 引用检测 → 检测记录”点击“手动复测”继续检查同一记录。“搜索收录监测”查看百度、必应索引情况，与 AI 是否在回答中引用文章分开判断。

## 环境隔离与浏览器自动化

EasyBR 管理独立环境、代理 IP 和指纹；Easy WebBridge 负责连接并操作具体环境中的已登录浏览器。一个扩展“在线”不代表所有账号都已授权。多人、多账号操作时始终按实际环境和平台身份核对，登录发生变化就重新确认。

登录或验证码由账号本人在官方页面处理。发布期间遇到验证、账号不一致、素材缺失或权限错误时，保留状态，先解决具体问题，再按原任务继续。
