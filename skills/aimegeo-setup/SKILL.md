# aimeGeo 下载与首次使用

## 触发条件

用户要求安装、更新、下载客户端、排查首次连接，或从一个网站/项目开始使用 aimeGeo。只问产品能力时先回答能力，不自动下载。

## 必要输入

操作系统与芯片、下载目录、已有安装状态、具体错误。未知时先指导查看系统信息。登录凭据与验证码由本人在官方界面输入，不收集。

## 公开资源

- 官网：https://geo.aimmme.com/
- 下载：https://geo.aimmme.com/download/
- 工作台：https://geo.aimmme.com/ag01/
- 安装帮助：https://geo.aimmme.com/docs/client-install/
- Easy WebBridge 安装：https://github.com/xxjrq/easy-webbridge ，按当前 README，不自造安装命令。
- 安装后的连接帮助：https://geo.aimmme.com/docs/publish-flow/
- 本包：[安装教程](../../docs/installation.md)、[FAQ](../../docs/faq.md)、[安装提示词](../../prompts/setup.md)。相对文件不存在时使用上述正式帮助，不猜测本机路径。

使用助手与加载 Skill 的步骤见[AI 使用方法](../../docs/ai-assistant.md)。本 Skill 不依赖产品私有源码或仓库外部脚本；缺少浏览器工具时提供手动操作步骤。

## 步骤

1. 确认系统、芯片与用户目标；当前已核实有 Apple Silicon arm64 Mac 和 Windows 包。Intel Mac/Linux 无已核实兼容包时说明限制。
2. 读取官方当前下载页，选择匹配资源。先说明来源和保存位置，再下载到用户指定目录；不能只凭文件名猜链接。
3. 报告实际下载结果。仅在有可信来源 SHA-256 时宣称来源校验通过；未知哈希不自造。
4. 按包内说明引导安装，不自动运行安装器或关闭系统安全机制。手动安装不需要 Node.js；本仓库可选查询/下载脚本需要 Node.js，不负责自动安装。
5. 更新时正常退出旧 aimeGeo，再开新版，保留平台浏览器。客户端与网页均登录本人同一个账号。
6. 需要账号同步、发布、网页 AI 检测时，保持客户端运行，在目标浏览器确认 Easy WebBridge 连接；在账号授权读取环境、同步并核对昵称、用户名、平台 ID 与头像。
7. 给出第一条小任务：整理一份资料、做一篇草稿、选择一个账号、准备一组问题。实际发布须具有用户本次明确的发布意图。

## 失败与恢复

| 现象 | 处理 |
| --- | --- |
| 无匹配包或资源不可用 | 回官方下载中心/官方支持，不提供猜测包 |
| 系统拦截或安装失败 | 核对来源与包内说明，保留错误文本，不绕过安全校验 |
| 扩展在线但工作台未连 | 检查客户端运行、同账号、环境授权和顶栏检测 |
| 平台登录/验证码 | 交由本人在原生界面完成，完成后重新核对身份 |
| 工具无网页/本机权限 | 提供手动步骤，明确未执行的动作 |

## 完成标准

报告系统、官方来源、实际文件位置、是否已安装启动、连接检查结果和仍缺条件。缺证据写待核验，不把下载完成写成安装完成。输出脱敏摘要，不公开账号凭据、本机环境标识或原始日志。
