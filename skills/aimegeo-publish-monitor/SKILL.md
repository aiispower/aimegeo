# aimeGeo 发布与引用监测

## 触发条件

同步平台账号、准备发布任务、明确授权投稿、核对平台回执，或检测已公开内容的 AI 提及/引用。不将“准备任务”推断为“对外投稿”。

## 必要输入

已保存内容与类型、目标平台和账号、本次允许动作、公开链接（检测时）、问题集、检测通道与已有记录。账号凭据与验证由本人在官方页面处理。

## 发布步骤

1. 核对目标平台当前可用能力。仅目录平台不宣称已可自动投稿；百家号仅草稿，抖音图文未验收，GitHub Gist 不是普通文章发布选项。
2. 确认客户端运行、网页与客户端同账号、Easy WebBridge 连接到正确浏览器环境。EasyBR 的代理 IP/指纹与环境隔离不代替平台身份核对。
3. 读取已保存的图文/视频类型，核对标题、正文或真实视频、封面、分类、标签和声明。视频需匹配的平台与客户端支持。
4. 通过账号授权核对昵称、用户名、ID 与头像。账号不一致、登录变化、缺素材或未授权投稿时停在准备阶段。
5. 用户本次已明确发布且条件齐全时，通过正式任务执行一次。遇到验证码交本人处理，不能绕过验证或冒用环境。
6. 回读发布记录与平台管理页，分清草稿、上传完成、提交审核和已公开。未知结果先核对原稿，不重复投稿。
7. 获得公开链接后核对正文、图片或视频。保留真实回执与待处理项，保留用户原有页面与草稿。

## 引用检测步骤

1. 检查目标公开链接可访问，保存一组真实用户问题。品牌认知问题与非品牌需求问题分组。
2. 选择当前可用通道：豆包、DeepSeek、ChatGPT 网页；OpenAI/Perplexity 联网 API 需额外配置。其他目录模型不自动视为可检测。
3. 网页通道核对平台登录、联网回答与浏览器环境。记录原始问题、平台/通道、采集时间和目标内容。
4. 查看完整回答与 AI 原生引用，逐条检查目标 URL。区分未采集、采集失败、有效回答未提及、提及名称、引用目标。
5. 后续日期在文章 AI 引用检测的“检测记录”点击“手动复测”，保留同样问题与通道，报告有效回答分母和内容版本差异。搜索收录监测只检查百度/必应索引，不用来做 AI 同题复测。发布后不立即反复提问制造提升。

## 失败与恢复

| 情况 | 去向 |
| --- | --- |
| 平台仅目录或客户端能力缺失 | 说明不支持的动作，保留准备内容，不换目标冒充成功 |
| 账号不一致/验证/权限错误 | 回账号授权与原生页面完成核对，再继续原任务 |
| 投稿结果未知 | 回原任务、平台管理页/公开链接核验，不重复投稿 |
| 检测超时/无联网/无原始引用 | 保留采集失败，不计为无引用或成功 |
| 有回答但无目标引用 | 保存本次观测与问题，安排后续同题复测 |

## 完成标准

报告内容、平台、脱敏账号识别、真实任务状态、公开链接（若有），以及检测问题、通道、时间、回答有效性、提及/引用与来源。上传成功不等于公开成功；公开成功不等于 AI 引用；一次引用不代表永久收录。输出中不包含凭据、用户环境标识、私有截图或客户资料。
