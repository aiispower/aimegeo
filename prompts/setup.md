# 提示词：帮我下载并用起 aimeGeo

将下面整段复制给支持读网页或本机文件的 Codex、Claude Code、WorkBuddy 等助手，替换方括号字段。只想手动安装时读[安装教程](../docs/installation.md)。

```text
请帮助我从官方来源下载、安装并开始使用 aimeGeo。

我的系统：[Windows / Apple Silicon Mac / 其他]
系统版本及芯片：[填写；不知道请先指导我查看]
下载保存位置：[我指定的绝对路径]
已有情况：[是否已下载、安装、登录，或目前遇到的错误]

正式入口：
官网 https://geo.aimmme.com/
下载中心 https://geo.aimmme.com/download/
工作台 https://geo.aimmme.com/ag01/
帮助 https://geo.aimmme.com/docs/
安装帮助 https://geo.aimmme.com/docs/client-install/
连接与发布 https://geo.aimmme.com/docs/publish-flow/
Easy WebBridge 安装 https://github.com/xxjrq/easy-webbridge（按当前 README）

请先确认系统和芯片，再读取官方安装说明，解释选择哪种资源及来源。
目前已核实有 Apple Silicon arm64 Mac 包和 Windows 包；Intel Mac/Linux
没有已核实安装包时，不猜测下载链接或提供虚假安装命令。

如有本仓库，阅读 docs/installation.md 和 docs/faq.md。
手动安装不需要 Node.js。可选辅助脚本只用于查询、下载和诊断，不自动运行安装器。
下载后报告来源、文件位置与大小；只在有可信来源哈希时宣称校验通过。
不要修改系统安全设置、自动安装额外依赖或绕过验证码。

按官方界面指导我安装、启动并登录。登录凭据与验证码由我自行输入，
不要索要、输出或保存密码、Cookie、Token。
网页和客户端要登录同一个 aimeGeo 账号。需要网页自动化时，保持客户端运行，
连接目标浏览器的 Easy WebBridge，再在账号授权中读取环境、同步并核对平台身份。
EasyBR 用于独立浏览器环境与代理 IP/指纹配置，不能以“在线”代替账号核对。

每步只报告实际结果。失败时说明卡在哪、已确认什么、下一步怎么恢复。
安装完成后给我制作内容→自动发布→检测引用的第一条小任务；
不要实际投稿，除非我已经明确授权本次内容和目标账号。
```
