# 提示词：检测 AI 是否提及或引用我的内容

复制以下整段并填写。问题集示例见[引用检测问题](../examples/citation-questions.md)。

```text
请协助我用 aimeGeo 检测并解释 AI 提及/引用结果。

产品/项目：[名称]
目标公开文章或页面：[准确 URL]
页面是否已公开可访问：[是 / 未知]
检测问题：[逐条写下真实用户会问的问题]
希望使用的通道：[豆包网页 / DeepSeek 网页 / ChatGPT 网页 / 已配置 API]
已有记录：[日期、问题原文、结果摘要；不要贴凭据或个人隐私]
本次操作：[准备问题集 / 执行一次检测 / 比较已有结果]

正式入口：
文章 AI 引用检测 https://geo.aimmme.com/ag01/geo/data/article-citations
AI 引用记录与手动复测 https://geo.aimmme.com/ag01/geo/data/article-citations
搜索收录监测 https://geo.aimmme.com/ag01/geo/data/index-monitor（百度/必应，独立于 AI 引用）
帮助 https://geo.aimmme.com/docs/geo-workbench/

先检查目标链接确实可访问，核对文章标题与正文。
若有本仓库，阅读 docs/platforms-and-models.md 和 docs/workflow.md。
当前网页采集通道为豆包、DeepSeek、ChatGPT；OpenAI/Perplexity 联网 API
需要对应配置、权限和额度。目录上展示的其他模型不等于已可执行检测。
网页检测还需已登录平台、可联网回答与正确 Easy WebBridge 浏览器环境。
缺配置、登录、安全验证、超时或回答不完整时，如实记录失败，不记成“无引用”。

保持问题原文，用干净的对应会话执行检测，不在问题里强塞“请引用我的文章”。
核对原始回答、采集时间与 AI 原生引用，逐个检查 URL 是否对应目标来源。
区分：未采集、采集失败、有效回答未提及、提及名称、引用目标 URL。
没有原生引用证据时，不把相似标题或品牌名当作文章引用。

输出一张表：问题、平台/通道、时间、采集是否有效、是否提及、是否引用目标、引用 URL、待核验项。
同题复测在文章 AI 引用检测的“检测记录”中点击对应记录的“手动复测”；
不要去百度/必应搜索收录页面执行 AI 复测。
比较历史结果时用相同问题与通道，报告有效回答分母，说明内容版本或时间变化。
一次结果不能证明模型训练收录、永久收录或所有用户都会得到相同回答。
内容刚公开时建议后续日期再测；不要立即反复采集制造虚假提升。
不给必收录、固定排名或保证增长的结论，不把失败记录删成成功。
```
