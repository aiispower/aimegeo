# 提示词：核对账号并发布一份内容

复制以下整段并填写。执行前确认你希望对外发布的内容、平台和账号；未写明的发布意图由助手先核对。[平台能力](../docs/platforms-and-models.md)会影响是否能自动完成。

```text
请协助我在 aimeGeo 发布以下内容，并核对真实结果。

内容来源：[文章/视频名称与可访问位置；不要贴私有密钥]
内容类型：[已保存的图文 / 视频]
目标平台：[填写]
目标账号：[供本人识别的名称，不贴登录凭据]
本次操作：[只检查与准备 / 明确授权发布这份内容到这个账号]
发布限制：[时间、封面、分类、标签、声明等]

正式入口：
账号授权 https://geo.aimmme.com/ag01/geo/publish/self-accounts
发布任务 https://geo.aimmme.com/ag01/geo/publish/self-tasks
发布记录 https://geo.aimmme.com/ag01/geo/publish/self-records
帮助 https://geo.aimmme.com/docs/publish-flow/

先核对当前平台能力和客户端支持。若有本仓库，读 docs/platforms-and-models.md。
平台有图标不等于可以自动发布。百家号当前只保存草稿；抖音图文未验收，
视频需匹配的平台、客户端与真实素材；GitHub Gist 不是普通文章发布选项。
目标仅在目录时说明限制，不临时换账号、换平台或假称已完成。

保持本机客户端运行，网页与客户端同一 aimeGeo 账号。
用 Easy WebBridge 连接已登录的真实浏览器，在绑定环境核对平台昵称、用户名、ID 和头像。
EasyBR 的独立环境、代理 IP 和指纹配置不能替代身份核对。
不要读取、输出或公开 Cookie、密码、Token；验证码由我在官方界面完成。

读取已保存的内容类型，逐项核对标题、正文/视频、封面、图片、标签和声明。
缺素材、账号不一致、未授权发布时停在准备阶段并说明缺项。
仅在本次发布已授权且条件齐全时，通过正式发布任务执行一次投稿。

保存并回读真实状态：草稿、上传完成、已提交、审核中、已公开。
未知状态先查询原任务和平台管理页，不能重试点击投稿制造重复文章。
获得公开链接后核对页面正文与图片，不能用执行结束代替公开成功。
结果报告包含内容名称、平台、账号识别名、任务状态、公开链接（若有）、待处理事项。
保持我的原有浏览器页面；不要把别的账号页面或未发布草稿当成临时对象清理。
不要把发布成功等同于 AI 引用成功；后续按引用检测提示词继续。
```
